# JJ AutoPost — ফেসবুক পেজে স্বয়ংক্রিয় ফটোকার্ড

প্রতিদিন নির্দিষ্ট সময়ে নিজে থেকেই কার্ড বানিয়ে আপনার পেজে পোস্ট করবে:

| কার্ড | কী থাকে | ডেটা কোথা থেকে |
|---|---|---|
| `good-morning` | শুভ সকাল + নতুন বার্তা + ইংরেজি ও বাংলা তারিখ | নিজস্ব (৩০টি বার্তা ঘুরে ঘুরে) |
| `weather` | প্রধান শহর + ৮ বিভাগের তাপমাত্রা ও বৃষ্টির সম্ভাবনা | Open-Meteo (ফ্রি) |
| `prayer` | ৬ ওয়াক্তের সময় + হিজরি তারিখ | Aladhan (ফ্রি) |
| `news-list` | সেরা ১০ / বিভাগভিত্তিক ৫টি শিরোনাম | Google News RSS |
| `single-news` | একটা খবরের বড় ফটোকার্ড (একই খবর দুবার আসবে না) | Google News RSS |

খবরের বিভাগ: `top`, `bangladesh`, `politics`, `sports`, `cricket`, `football`, `world`, `business`, `entertainment`, `tech` — নতুন বিভাগ `config/pages.json`-এর `news` অংশে যোগ করা যায়।

পুরো সিস্টেম চলে **GitHub Actions**-এ, তাই নিজের কম্পিউটার বা সার্ভার চালু রাখতে হয় না।

### রিলস (খাড়া ভিডিও, বাংলা ভয়েস + হালকা মিউজিক)

| ধরন | কী থাকে | কনফিগে যা দিতে হয় |
|---|---|---|
| `reel-news` | শুরু → প্রতিটা শিরোনাম আলাদা স্লাইডে → ফলো করুন | `"news": "top"`, `"count": 5` |
| `reel-breaking` | "ব্রেকিং নিউজ" স্টাইলে একটা খবর | `"news": "cricket"` ইত্যাদি |
| `reel-weather-prayer` | আবহাওয়া → ৮ বিভাগ → নামাজের সময় | — |
| `reel-morning` | শুভ সকাল + বার্তা | — |
| `reel-lines` | ভালোবাসা / মনের কথা / অনুপ্রেরণা / একটু হাসি | `"lines": "love"`, `"count": 3` |

- **লেখার ভাণ্ডার:** `content/lines.json`। এখানে নিজের লেখা যোগ করা যায়, নতুন বিভাগও বানানো যায় (যেমন `"islamic"`, `"friendship"`)। একই লেখা সব শেষ না হওয়া পর্যন্ত আবার আসে না।
- **ভয়েস:** Microsoft Edge-এর ফ্রি বাংলা কণ্ঠ (`edge-tts`)। নারী কণ্ঠ `bn-BD-NabanitaNeural`, পুরুষ কণ্ঠ `bn-BD-PradeepNeural`। পেজভেদে `reelVoice` দিয়ে বদলানো যায়। এটা অফিশিয়াল ফ্রি সার্ভিস নয় — বন্ধ হয়ে গেলে রিল ভয়েস ছাড়া শুধু মিউজিক দিয়ে তৈরি হবে, কাজ থামবে না।
- **মিউজিক:** ডিফল্টে কোডে বানানো নরম সুর (কপিরাইটমুক্ত)। নিজের রয়্যালটি-ফ্রি mp3 `assets/music/` ফোল্ডারে রাখলে সেগুলো থেকে ঘুরে ঘুরে নেবে। জনপ্রিয় গান রাখবেন না — রিল মিউট বা ব্লক হতে পারে।
- **পোস্ট:** ফেসবুকের Reels API দিয়ে। সেটা একদম শুরুতেই কাজ না করলে সাধারণ ভিডিও হিসেবে পোস্ট করার চেষ্টা করে।
- টকশো বা আড্ডার মতো আসল মানুষের কথাবার্তা স্বয়ংক্রিয়ভাবে বানানো যায় না — সেগুলো নিজে রেকর্ড করতে হবে।

## সেটআপ (একবারই করতে হবে)

### ধাপ ১ — GitHub-এ রিপোজিটরি
1. github.com → **New repository** → নাম `jj-autopost` → **Private** → Create।
2. এই ফোল্ডারের সব ফাইল সেখানে আপলোড করুন (`.github` ফোল্ডারসহ — এটা না থাকলে অটোমেশন চলবে না)।
   ফোন থেকে `.github` ফোল্ডার আপলোড ঝামেলার হতে পারে, কম্পিউটার থেকে করা সহজ। চাইলে খালি রিপো বানিয়ে নামটা Claude-কে দিন, সে নিজেই পুশ করে দিতে পারবে।

### ধাপ ২ — Facebook App ও পেজ টোকেন (মোবাইল থেকেও করা যায়)
মোবাইলে Chrome-এ ⋮ মেনু থেকে **Desktop site** চালু করে নিন। নিচের পাতাগুলো মোবাইল ভিউতে ঠিকমতো আসে না।

1. **ডেভেলপার অ্যাকাউন্ট:** [developers.facebook.com](https://developers.facebook.com) → Get Started। ফোন নম্বর যাচাই চাইতে পারে।
2. **App বানানো:** My Apps → **Create App** → নাম `JJ AutoPost`। Use case জিজ্ঞেস করলে পেজ পরিচালনা সংক্রান্ত অপশন, না পেলে **Other** → ধরন **Business**। (মেনুর নাম সময়ের সাথে বদলায়।)
3. **টোকেন নেওয়া:** [Graph API Explorer](https://developers.facebook.com/tools/explorer) → ডানে **Meta App**-এ `JJ AutoPost` → **Add a permission**-এ এই তিনটা: `pages_show_list`, `pages_manage_posts`, `pages_read_engagement` → **Generate Access Token** → যেসব পেজে অটো পোস্ট চান সবগুলো টিক দিন → Done। (এই টোকেন প্রায় ১ ঘণ্টা টেকে।)
4. **মেয়াদ বাড়ানো:** টোকেনের পাশের **ⓘ** → **Open in Access Token Tool** → নিচে **Extend Access Token** → নতুন যে লম্বা টোকেন আসে সেটা কপি করুন (প্রায় ২ মাস টেকে)।
5. **পেজ টোকেন:** Explorer-এ ফিরে Access Token ঘরে ওই নতুন টোকেন বসান → উপরের ঘরে লিখুন `me/accounts` → **Submit**। নিচে প্রতিটা পেজের নাম, id আর access_token আসবে। এই পেজ টোকেনগুলোর মেয়াদ সাধারণত শেষ হয় না।
6. **পুরো লেখাটা কপি করুন** — শুরুর `{` থেকে শেষের `}` পর্যন্ত।

> নিজে পরীক্ষা করতে চাইলে: যেকোনো একটা পেজ টোকেন [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken/)-এ বসিয়ে Debug দিন — **Expires: Never** দেখালে ঠিক আছে।
> ফেসবুকের পাসওয়ার্ড বদলালে বা পেজের অ্যাডমিন থেকে সরলে টোকেন বাতিল হয়। তখন ধাপ ৩–৬ আবার করে Secret আপডেট করবেন।

### ধাপ ৩ — GitHub Secret রাখা
রিপো → **Settings → Secrets and variables → Actions → New repository secret**
- Name: `FB_PAGE_TOKENS`
- Secret: ধাপ ২-এ কপি করা পুরো লেখা

কোন টোকেন কোন পেজের, সেটা ফেসবুক পেজের **নাম** দেখে নিজে মিলিয়ে নেয় (`config/pages.json`-এর `name`)। ফেসবুকে পেজের নাম আলাদা হলে সেই পেজের ব্লকে `"fbName": "ফেসবুকের হুবহু নাম"` বা `"pageId": "id"` লিখে দিন।
(কম্পিউটার থাকলে `tools/token-helper.html` দিয়েও এই কাজ করা যায়।)

### ধাপ ৩.৫ — টোকেন যাচাই
Actions → JJ AutoPost → Run workflow → type: **check-tokens** → Run। ১–২ মিনিটে রানের পাতায় দেখাবে কোন পেজ কোন ফেসবুক পেজের সাথে মিলেছে। কিছু পোস্ট হয় না।

### ধাপ ৩.৬ — App-কে Live করা (জরুরি)
App **Development** মোডে থাকলে API দিয়ে করা পোস্ট শুধু আপনি দেখবেন, অন্যরা দেখবে না। তাই App Dashboard-এ মোড **Live** করে দিন। Live করতে **Privacy Policy URL** চাইতে পারে (App settings → Basic)।

### ধাপ ৪ — প্রথমে টেস্ট (পোস্ট হবে না)
রিপো → **Actions** → **JJ AutoPost** → **Run workflow** → `dry_run` টিক দেওয়া রেখে Run।
শেষ হলে রানটা খুলুন → নিচে **Artifacts** থেকে `cards-...` ডাউনলোড করে কার্ডগুলো দেখুন। আসল আবহাওয়া, নামাজের সময় আর খবর ঠিক আসছে কিনা এখানেই মিলিয়ে নিন।

> প্রথম আসল পোস্ট টেস্ট: page = `jj-official`, type = `good-morning`, `dry_run` টিক তুলে দিয়ে Run — শুধু একটা কার্ড পোস্ট হবে।
>
> ⚠️ হাতে চালানোর সময় `dry_run`-এর টিক তুলে দিলে বেছে নেওয়া পেজের **সব কার্ড একসাথে** পোস্ট হয়ে যাবে। একটা কার্ড পরীক্ষা করতে `page` ও `type` দুটোই নির্দিষ্ট করে দিন।

### ধাপ ৫ — চালু
আর কিছু করতে হবে না। প্রতি ঘণ্টায় (১৭ মিনিটে) নিজে থেকে চলে, যে পোস্টের সময় হয়েছে সেটা পোস্ট করে। GitHub দেরি করলেও ৩ ঘণ্টার মধ্যে বাকি পোস্ট করে দেয় (`catchUpHours`)। কোনো পোস্ট ব্যর্থ হলে GitHub আপনার ইমেইলে জানাবে।

## নিয়মিত কাজ

**পোস্টের সময় বা পেজ বদলানো** — `config/pages.json` এডিট করুন (GitHub-এর ওয়েবসাইটেই করা যায়):
```json
{ "time": "21:00", "type": "news-list", "news": "top", "count": 10, "title": "আজকের সেরা ১০ খবর" }
```
সময় বাংলাদেশ সময়ে, ২৪ ঘণ্টার হিসাবে। ঘণ্টার মধ্যে মিনিট ধরে নিখুঁত হবে না — প্রতি ঘণ্টায় একবার চলে।

**নতুন পেজ যোগ** — `pages`-এ একটা ব্লক কপি করে `id`, `name`, রঙ (`theme`) আর `posts` বদলান, তারপর ধাপ ২-৩ আবার করে নতুন টোকেনসহ Secret আপডেট করুন। প্রতিটা পেজের রং ও সময় আলাদা রাখুন।

**লোগো** — `assets/logos/<পেজের id>.png` নামে PNG রাখলে লেখার বদলে আপনার লোগো বসবে (যেমন `assets/logos/jj-news.png`, স্বচ্ছ ব্যাকগ্রাউন্ড ভালো)।

**শহর বদলানো** — পেজের `weatherCity` / `prayerCity`-তে নাম, `lat`, `lon` দিন। JJ Official-এ উল্লাপাড়ার যে স্থানাঙ্ক দেওয়া আছে সেটা আনুমানিক — Google Maps থেকে মিলিয়ে নিন।

**কম্পিউটারে প্রিভিউ** (Node.js লাগবে): `npm ci` → `npx playwright install chromium` → `npm run preview` (নমুনা ডেটা) বা `npm run preview-live` (আসল ডেটা)। কার্ড আসবে `out/` ফোল্ডারে।

## যা জেনে রাখা দরকার (সৎভাবে)

- **খরচ:** প্রাইভেট রিপোতে GitHub ফ্রি অ্যাকাউন্টে মাসে ২,০০০ মিনিট পাওয়া যায় বলে জানি (বদলে থাকতে পারে, Settings → Billing-এ দেখুন)। এখনকার নমুনা কনফিগে দিনের প্রায় ১৭টা ঘণ্টায় কিছু না কিছু পোস্ট আছে, প্রতিটা রান আনুমানিক ২–৪ মিনিট — মাসে মোটামুটি ১,৫০০–২,২০০ মিনিট, অর্থাৎ **সীমা ছাড়িয়ে যেতে পারে**। সমাধান: রিপো **Public** করা (Settings → General → Danger Zone → Change visibility) — পাবলিক রিপোতে স্ট্যান্ডার্ড রানারের মিনিটের সীমা নেই বলে জানি; Secret (টোকেন) তখনও গোপন থাকে, শুধু কোড আর কনফিগ সবাই দেখতে পাবে। অথবা পোস্টের সময়গুলো কম ঘণ্টায় গুছিয়ে আনা।
- **শিডিউলের দেরি:** GitHub-এর cron ব্যস্ত সময়ে দেরিতে চলতে পারে, কখনো এক রান বাদও পড়তে পারে।
- **খবরের কপিরাইট:** কার্ডে শুধু শিরোনাম আর সূত্রের নাম যায়, অন্যের ছবি বা লেখা নয়। এটা তুলনামূলক নিরাপদ, কিন্তু পুরোপুরি ঝুঁকিমুক্ত বলে আমি নিশ্চিত করতে পারি না। Google News RSS ব্যক্তিগত ব্যবহারের জন্য — বাণিজ্যিক বড় ব্যবহারে তাদের শর্ত আলাদা হতে পারে।
- **ফেসবুকের স্প্যাম ফিল্টার:** অনেক পেজে একই সময়ে প্রায় একই কনটেন্ট দিলে রিচ কমতে পারে বা পেজ সীমিত হতে পারে। তাই নমুনা কনফিগে পেজগুলোর সময় ও বিভাগ আলাদা রাখা হয়েছে।
- **নামাজের সময়:** গণনাভিত্তিক — ইসলামিক ফাউন্ডেশনের সময়সূচির সাথে কয়েক মিনিট পার্থক্য হতে পারে। হিজরি তারিখও চাঁদ দেখার কারণে বাংলাদেশে এক দিন আগে-পরে হতে পারে।
- **Graph API সংস্করণ:** `config/pages.json`-এ `graphVersion: "v23.0"` আছে। Facebook পুরোনো সংস্করণ একসময় বন্ধ করে — ত্রুটি দেখালে নতুন সংস্করণ নম্বর বসাবেন (developers.facebook.com/docs/graph-api/changelog)।
- **রিপো নিষ্ক্রিয়তা:** অনেক দিন রিপোতে কোনো পরিবর্তন না হলে GitHub শিডিউল বন্ধ করে দিতে পারে বলে জানি। এখানে প্রতিটা পোস্টের পর `state/posted.json` আপডেট হয়ে কমিট হয়, তাই সাধারণত সমস্যা হওয়ার কথা নয়।
