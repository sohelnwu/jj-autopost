🔑 GitHub টোকেন

এটা দিয়ে অ্যাপ আপনার GitHub-কে কাজ শুরু করতে বলে। টোকেন শুধু এই ফোনেই থাকে।

টোকেন কীভাবে বানাবেন?
  1. এই পাতা খুলুন (মোবাইলে Desktop site চালু করুন)
  2. Token name: JJ Studio, Expiration: No expiration বা ১ বছর
  3. Repository access: Only select repositories → jj-autopost
  4. Permissions → Repository permissions → Actions: Read and write
  5. Generate token → কপি করে উপরে বসান

ℹ️ কীভাবে কাজ করে

"তৈরি করো" চাপলে আপনার GitHub (sohelnwu/jj-autopost) একটা কাজ চালু করে: বিষয় অনুযায়ী গত ২৪ ঘণ্টার সবচেয়ে আলোচিত খবর বাছাই করে, Gemini কণ্ঠে রিল আর ফটোকার্ড বানায়, তারপর এখানে পাঠায়। কোনো রিল বা কার্ডে কোনো লিংক থাকে না — শুধু সূত্রের নাম।
